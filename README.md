# CVMatch

Веб-приложение для подбора кандидатов: рекрутёры описывают позиции, кандидаты
один раз заполняют профиль, а резюме под каждую позицию приложение собирает
само.

## Идея

Обычно кандидат переписывает одно и то же резюме под каждую вакансию. Здесь
наоборот: профиль — единственный источник данных, а позиция задаёт шаблон —
какие поля показать, в каком порядке и какими секциями. Резюме своих значений
не хранит: правка поля прямо в резюме меняет профиль, и остальные резюме
кандидата обновляются вместе с ним.

Набор полей не зашит в код. Рекрутёры ведут общую библиотеку атрибутов
(«Годы опыта», «Уровень английского», «Сертификаты»), каждый со своим типом —
строка, текст, число, дата, период, флаг, список, изображение, — и собирают
из них шаблон позиции.

## Роли

**Кандидат** заполняет профиль, ведёт список проектов с тегами и описанием
в Markdown, подаёт резюме на позиции и публикует их.

**Рекрутёр** создаёт позиции и шаблоны, ведёт библиотеку атрибутов, ищет по
всем опубликованным резюме, ставит лайки и обсуждает кандидатов в ветке
позиции.

**Администратор** управляет пользователями (роли, блокировка, удаление) и
открывает любую страницу как её владелец — например, чтобы поправить опечатку
в чужом профиле.

## Возможности

- **Правила доступа к позиции** — позиция бывает открытой или закрытой.
  Закрытая пускает только тех, чей профиль удовлетворяет всем её условиям
  (опыт ≥ 3 лет, английский не ниже B2); проверка идёт на сервере при попытке
  подать резюме.
- **Полнотекстовый поиск** по резюме: значения профиля, названия и описания
  проектов, теги, заголовок позиции. Каталог позиций ищется через `tsvector`
  PostgreSQL.
- **Экспорт резюме позиции** в CSV или Excel: строка на кандидата, колонка на
  поле шаблона — чтобы сравнивать отклики в таблице.
- **Печатный PDF резюме** с QR-кодом, ведущим обратно на страницу этого резюме
  в приложении.
- **Обсуждение позиции** — общая ветка для рекрутёров, обновляется опросом.
- **Вход** по паролю с подтверждением email либо через Google или GitHub.
- **Две темы и два языка** (русский, английский); выбор хранится в профиле
  пользователя и переносится между устройствами.

## Стек

**Бэкенд** — PHP 8.4, Symfony 7.4, Doctrine ORM 3, PostgreSQL 16. JWT для
аутентификации (LexikJWTAuthenticationBundle), OAuth через
KnpUOAuth2ClientBundle, почта — Symfony Mailer. PDF собирает Dompdf, QR-коды —
endroid/qr-code.

**Фронтенд** — React 19, TypeScript, Vite, React Router 7, axios. Оформление —
собственная система на CSS-переменных, без UI-фреймворка: Bootstrap остался в
зависимостях, но в коде не используется. Иконки — Phosphor, Markdown —
react-markdown, изображения хранятся в Cloudinary.

**Инфраструктура** — Docker Compose: nginx как единая точка входа, php-fpm,
Vite dev server и PostgreSQL.
